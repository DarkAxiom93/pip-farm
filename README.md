# חוות הפיפים

יצורים קטנים שמתחילים כאחד, מתפצלים כשעושים איתם משימות, מדברים בשפה משלהם ויודעים שהם בתוך משחק.
המשחק רץ בשתי צורות מאותו קוד:
- **בדפדפן:** כ-Artifact של Claude.
- **ב-Windows:** אפליקציה עם פיפים על שולחן העבודה, התראות ועדכונים אוטומטיים.

## התקנה ב-Windows
1. מורידים את `PipFarm-Setup-<גרסה>.exe` מעמוד ה-[Releases](https://github.com/DarkAxiom93/pip-farm/releases/latest).
2. Windows יציג אזהרת SmartScreen, כי הקובץ לא חתום. לוחצים "מידע נוסף" ואז "הפעל בכל זאת".
3. מכאן והלאה החווה **מתעדכנת לבד**:
   - היא בודקת אם יש גרסה חדשה כשהיא עולה, ואחר כך כל 6 שעות.
   - הגרסה החדשה יורדת ברקע ומותקנת כשסוגרים את החווה.
   - אפשר גם להתקין מיד, דרך ההגדרות בלשונית "חווה" או דרך האייקון ליד השעון.

## מה יש בגרסת המחשב
- **חלון החווה:** סגירת החלון לא עוצרת את החווה, היא ממשיכה לחיות באייקון ליד השעון.
- **חברים על שולחן העבודה:** פס שקוף בתחתית המסך שבו פיפים מטיילים.
  - קליק עונה לצורך של הפיפ.
  - קליק כפול פותח את החווה עליו.
- **התראות Windows:** כשפיפ צריך אותך, כשמגיע אורח, כשנופל מטאור וכשזמן ריכוז נגמר.
- **Claude (אופציונלי):** מפתח API בהגדרות, שנשמר מוצפן רק על המחשב. בלי מפתח, הפיפים מבינים לפי מילות מפתח.
- **שמירה:** `%APPDATA%\Pip Farm\farm.json`, ולידו גיבוי `farm.json.bak`.

## מבנה הקוד
```
game/
  template.html          HTML ו-CSS של המשחק, עם סימון למקום של הקוד
  src/*.ts               המשחק עצמו, מחולק לפי נושאים (עולם, פיפים, סיפור, ציור, קלט...)
                         הקבצים חולקים scope אחד ומחוברים לפי סדר השמות
  platform/web/          מה ששונה בדפדפן (כמעט כלום)
  platform/desktop/      שמירה לקובץ, התראות, Claude דרך מפתח, עדכונים
  platform/test/         חיבור קטן לבדיקות בלבד
  main.ts                מפעיל את המשחק
main.js, preload.js      האפליקציה של Windows (Electron)
renderer/buddy.html      הפס של הפיפים על שולחן העבודה
scripts/build-game.mjs   בודק טיפוסים ובונה את web/pip-farm.html ואת renderer/index.html
tests/                   בדיקות דפדפן לכל ענפי הסיפור, ובדיקת עומס עם 112 פיפים
```

## פקודות
```
npm install
npm run typecheck   # בדיקת TypeScript לשתי הגרסאות
npm test            # בונה ומריץ את בדיקות הדפדפן (צריך python ו-playwright)
npm start           # מריץ את האפליקציה
npm run dist        # בונה קובץ התקנה לתיקייה dist
```

## שחרור גרסה חדשה
1. מעלים את `version` ב-`package.json`, למשל ל-`1.3.1`.
2. עושים commit ומעלים tag תואם:
   ```
   git tag v1.3.1 && git push origin main --tags
   ```
3. GitHub Actions בונה את קובץ ההתקנה על Windows ומפרסם Release.
4. כל החוות המותקנות מתעדכנות לבד.
